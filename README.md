A tiny stack virtual machine in one file: `main.ts` runs every program of a set on the tiny stack ISA — wrapping 32-bit arithmetic, a 256-value stack, calls, memory, input and output, and all ten traps with their exact exit codes.

## Run it

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```
